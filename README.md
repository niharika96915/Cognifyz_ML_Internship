# Cognifyz Technologies — Machine Learning Internship

This repository contains three machine learning projects completed as part of my Machine Learning Internship at Cognifyz Technologies.

## Projects

### Task 1: Predict Restaurant Ratings
Built a machine learning model to predict restaurant aggregate ratings using restaurant-related features.

### Task 2: Restaurant Recommendation
Developed a content-based restaurant recommendation system based on user preferences.

### Task 3: Cuisine Classification
Developed a machine learning classification model to predict a restaurant's primary cuisine using selected restaurant features.
